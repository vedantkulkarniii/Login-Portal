# Fake University Result Portal (Prank Site) 🎓😜

A responsive, mobile-first web application that mimics a university examination result portal. It features a realistic login form with CAPTCHA validation, which leads to a "Processing" screen and finally reveals a meme.

## 📱 Features
- **Mobile-First Design**: Optimized for phones and tablets.
- **Realistic UI**: Uses academic color palettes and professionally styled forms.
- **Prank Logic**:
  - Requires valid PRN and Captcha.
  - Simulates a 2-second database fetch.
  - Redirects to a full-screen meme result.
- **Security Check**: Disables right-click and inspect element shortcuts to hide the prank.

## 🚀 How to Deploy on GitHub Pages (Free)

1. **Upload to GitHub**:
   - Create a new repository on GitHub (e.g., `result-portal-prank`).
   - Upload all these files (`index.html`, `result.html`, `style.css`, `script.js` and images) to the repository.

2. **Enable GitHub Pages**:
   - Go to your repository **Settings**.
   - Click on **Pages** in the left sidebar.
   - Under **Source**, select `Deploy from a branch`.
   - Set the branch to `main` (or `master`) and folder to `/ (root)`.
   - Click **Save**.

3. **Share the Link**:
   - Wait a minute, and GitHub will verify the deployment.
   - It will give you a link like `https://yourusername.github.io/result-portal-prank/`.
   - Send this link to your friends on WhatsApp/SMS!
